K. BOOST 암흑기방어형 백테스터
제작일: 2026-11-26

1. 사용할 파일
   index.html 한 개입니다. 압축을 풀어 HTML을 사용하세요.
   기존 #k= 접속 링크의 키를 그대로 사용합니다. 새 키를 만들 필요가 없습니다.

2. 기존 사이트를 그대로 두고 별도로 사용하려면
   GitHub 저장소에 k 폴더를 만든 뒤 k/index.html로 올리세요.
   파일명은 index.html을 유지합니다. 기존 접속 주소에서 /soxl-backtester/ 뒤에
   k/를 넣고 기존 #k= 부분을 그대로 붙이면 별도 K 페이지가 됩니다.
   예: 기존 사이트 경로 /soxl-backtester/ → 별도 경로 /soxl-backtester/k/
   이 자료를 만든 과정에서는 GitHub 저장소와 기존 사이트를 수정하지 않았습니다.

3. 화면에서 선택
   실행 버전 → K. BOOST 암흑기방어형
   A~J도 같은 파일 안에 들어 있어 기존 버전과 비교할 수 있습니다.
   날짜 아래 6A(파랑) / F(보라)는 그날의 신규 운용 기준입니다.
   포트의 'CORE 출처 6A / F'는 기존 보유분 출처를 보여 줍니다.

4. 검증값 확인
   'K 검증 조건 적용'을 누르면 2020-01-02~2026-11-24,
   초기금 $10,000, 수수료 0.05%, SEC 반영, 무입출금 조건으로 복원합니다.
   최종자산 $35,284,157.54 / CAGR 227.0365618746% / MDD -27.7897567740%
   1,734거래일 중 6A 1,481일 / F 253일입니다.
   K 패널에 'K Work 검증 지문 일치'가 표시됩니다.

5. 날짜와 데이터
   처음 열면 오늘 날짜 선택 유지가 켜집니다. 확보한 마지막 완료 거래일까지만 계산합니다.
   내장 자료는 2026-11-24까지입니다. 기존 원장 자동 연결과 새 데이터 확장 기능을 유지했습니다.
   실제 브라우저에서 원장 11/25를 읽고 1,735일·F 254일로 확장 계산되는 것을 확인했습니다.
   새 자료를 읽지 못해도 확보한 마지막 거래일이 화면에 표시됩니다.

6. 조절 가능한 항목
   K: 시작·종료일, 초기금, 수수료. 각 조건마다 독립 shadow를 다시 계산합니다.
   K의 SF/AG, 분할 참조, 갱신 10일, 수익95%/손실45%와 SEC 반영은 검증 규칙으로 고정합니다.
   K의 입출금·수동 SF/AG·추가 파라미터 최적화는 지원하지 않으며 오류로 안내합니다.
   A~J의 기존 모드 설정과 최적화 메뉴는 유지했습니다.

7. CSV
   일별 거래, 완료 거래, 실제·기본·RSI 전환, LOT 출처, 원시 주문을 저장할 수 있습니다.
   화면 필터를 F 날짜로 제한해도 CSV는 전체 선택 기간을 저장합니다.

   실전 주문 기능은 없습니다. 실전 시트·CORE·계좌·자동주문 설정은 변경하지 않았습니다.
